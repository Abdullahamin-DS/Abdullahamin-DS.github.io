# Abdullah Amin — Data Science Portfolio

A responsive, modern dark portfolio website built with plain HTML and CSS for GitHub Pages. No framework, package installation, or build step is required.

## Files
- `index.html` — the portfolio website
- `Abdullah-Amin-CV.pdf` — add your CV PDF here to enable the Download CV button

## Preview on your computer
1. Extract the ZIP file.
2. Open the folder.
3. Double-click `index.html`; it opens in your browser.

## Publish with GitHub Pages
1. Sign in to https://github.com/ or create an account.
2. Click **New repository**.
3. Name the repository exactly `YOUR-GITHUB-USERNAME.github.io` (replace the placeholder with your actual GitHub username).
4. Choose **Public**, then create the repository.
5. Upload `index.html` to the repository's root. Also upload `Abdullah-Amin-CV.pdf` if you want the CV download link to work.
6. Open the repository's **Settings** → **Pages**.
7. Under build/deployment, choose **Deploy from a branch**; select branch `main` and folder `/ (root)`, then save.
8. Wait a few minutes and visit `https://YOUR-GITHUB-USERNAME.github.io/`.

## Editing the website
Open `index.html` in a text editor such as Visual Studio Code or Notepad. Search for the text you want to change and edit it. Save the file, refresh your browser, then upload the updated file to GitHub.
