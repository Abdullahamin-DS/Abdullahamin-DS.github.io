# Abdullah Amin — Data Science Portfolio

This is a responsive dark-themed portfolio built with HTML and CSS for GitHub Pages.

## Files
- `index.html` — portfolio website
- `profile-photo.jpeg` — profile photo used on the homepage
- `Abdullah-Amin-CV.pdf` — downloadable CV
- `README.md` — instructions

## Publish / update on GitHub Pages
1. Open your repository: https://github.com/Abdullahamin-DS/Abdullahamin-DS.github.io
2. Click **Add file → Upload files**.
3. Upload `index.html`, `profile-photo.jpeg`, and `Abdullah-Amin-CV.pdf`.
4. Choose **Commit changes**. If prompted, confirm replacing the existing files.
5. Open **Settings → Pages** and make sure the source is `Deploy from a branch`, branch `main`, folder `/(root)`.
6. Wait a few minutes, then visit https://Abdullahamin-DS.github.io/

The portfolio includes your profile photo, phone number, GitHub and LinkedIn links, and removes the Intermediate (ICS) education entry.
